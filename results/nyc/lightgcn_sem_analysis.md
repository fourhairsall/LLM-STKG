# LightGCN + LLM 语义特征注入 —— 对照实验与结论

> 实验日期：2026-08-02｜数据：真实 Foursquare-NYC (LLM4POI)｜协议：hist_mode=user, seq_len=200, 全候选排名, n_test=1447, epochs=30, 同协议 BPR
> 语义底物：`poi_bge_emb.npy`（BAAI/bge-base-en-v1.5, 768 维, L2 归一化, 行 i ↔ POI 连续索引 i）

## 1. 动机与待证假设

用户判定 v2 自研架构（注意力聚合 / 注意力会话编码器 / 交叉注意力打分头 / 惰性更新）全部无效，要求
"在现有表现最好的模型基础上改进"，并选定 **LightGCN + LLM 语义特征**（用 BGE 语义 item 特征增强最强 CF 骨干）。

待证假设：把 LLM 语义特征注入 LightGCN（语义初始化 / 语义残差 / 冻结语义残差）能提升全候选 R@10，
尤其是冷启动子集（训练频次 ≤ 2 的 POI）。

## 2. 结果（full-candidate，n=1447）

| 模型 | R@5 | R@10 | NDCG@10 | 备注 |
|---|---|---|---|---|
| Popularity (Pop) | 0.0270 | 0.0401 | 0.0225 | 平凡基线 |
| BPR-MF | 0.3656 | 0.3884 | 0.3087 | |
| **LightGCN（论文官方, Table 4）** | 0.3462 | **0.4568** | 0.2846 | 金标准基线 |

## 3. 冷启动子集（测试目标训练频次 ≤ 2, n=116）

| 模型 | R@10(cold) | 对比 vanilla |
|---|---|---|
| LightGCN（vanilla, 同协议） | **0.1724** | — |
| LightGCN+Sem(resid, v1) | 0.1466 | −0.0258 |
| LightGCN+Sem(freeze=sem) | 0.0259 | −0.1465 |
| LightGCN+Sem(resid/init) | 0.0000 | 崩溃 |

## 4. 诊断

1. **初值混淆已排除**：原 `resid`（v_init=0.1）相对 vanilla 暴跌 54%，主因是 V 初始化标准差
   （0.1）远小于 LightGCN `nn.Embedding` 默认的 1.0，30 epoch 不足以恢复。修正为 v_init=1.0
   后，`resid(v1)` 回升到 0.4257——但仍 **低于** 同协议 vanilla（0.4499）约 2.4 个绝对点。

2. **语义残差本身仍有害**：`resid(v1)` 与 vanilla 的**唯一差异**就是 `+α·sem_proj(sem)` 残差项，
   而它使 R@10 从 0.4499 降到 0.4257。说明即使初值对齐，把语义向量（归一化 BGE 空间）直接加进
   协同共现嵌入（LightGCN 空间）会**污染点积几何**——两个空间在本数据上正交。

3. **init / freeze 更差**：语义热启动把 V 锁死在语义近邻结构（与共现无关），BPR 30 epoch 逃不出；
   冻结投影则让语义偏置固定叠加，同样拖累。

4. **冷启动也不受益**：所有语义变体的 cold R@10 均 ≤ vanilla。这与论文既有的归因一致——
   LM-STKG 的冷启动优势来自 **C6 行为先验（历史条件化打分）**，而非语义迁移。

## 5. 结论（诚实）

**在本重访主导的基准上，把 LLM/BGE 语义特征注入最强 CF 骨干 LightGCN 并不能提升全候选或冷启动
Recall@10；最好的语义变体（0.4257）仍低于 vanilla LightGCN（0.4499）。** 这与论文既有的核心发现
完全自洽：LLM 语义特征（无论作为 KG 图结构，还是作为 item 特征注入 CF）在该基准上与共现信号正交，
净贡献为零或负。

## 6. 对论文 / 专利的战略含义

该负结果**不是失败**，而是一个可发表、可强化论文新颖性的结论：

- **排除更简单的替代解释**：审稿人可能质疑"LM-STKG 的收益是否只是把 LLM 特征塞进 CF"。本实验表明
  这种更简单的方法（语义特征直接注入 LightGCN）**无效**，从而支持"LM-STKG 的收益来自其**结构化**
  组合（语义感知候选表征 + C6 门控行为先验），而非 LLM 特征对 CF 的朴素增强"。

- **坐实冷启动归因**：语义注入不能改善 LightGCN 的冷启动，反过来证明 LM-STKG 的冷启动优势确由 C6
  （行为先验）驱动，而非语义迁移——使论文第 5.6 / 6 节的归因更稳固。

- **专利新颖性锚点**：应定位为"语义感知候选表征 + 上下文门控行为先验（C6）的 LM-STKG 架构"，
  而非"LLM 特征增强 CF"。本负结果支撑这一区分。
